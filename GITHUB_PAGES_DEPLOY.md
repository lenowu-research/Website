# GitHub Pages Deploy Guide

This website is already ready for GitHub Pages.

## Files to Upload

Upload these items to the root of your GitHub repository:

- `index.html`
- `styles.css`
- `script.js`
- `assets/`
- `.nojekyll`

## GitHub Setup

1. Create a new GitHub repository.
2. Upload the website files.
3. Open the repository.
4. Go to `Settings` -> `Pages`.
5. Under `Build and deployment`:
   `Source` -> `Deploy from a branch`
6. Under `Branch`:
   `main` and `/ (root)`
7. Click `Save`.

## Published URL

GitHub Pages usually gives you:

`https://YOUR_USERNAME.github.io/YOUR_REPOSITORY_NAME/`

If you name the repository exactly:

`YOUR_USERNAME.github.io`

then the site can live at:

`https://YOUR_USERNAME.github.io/`
